# midi.blue

The front door for bMiDi — the score the contract already wrote. The domain
was registered openly after it lapsed; this page renders the MiDi inscription
contracts' own music (default B, `0xf7Cf2DF5…9352d6`). The door is the
creator's if they want it — see the disclosure at the top of the page.

- one self-contained file, no CDN, no build step, zero off-origin beyond keyless RPC reads
- indigo palette, the token's own art colours — deliberately not estate chrome tokens
- live price from the pool's own V3 oracle via `observe()` — no price API
